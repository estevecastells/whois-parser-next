# WHOIS parser audit, DNS Magnitude ranks 226-250

Date: 2026-09-19

## Scope and source

This is a point-in-time port-43 WHOIS audit for the exact ICANN DNS Magnitude
ranks 226 through 250 in the 2026-09-12 snapshot, generated on 2026-09-18.
The source rank is retained below, including delegated domains that do not
expose public port-43 WHOIS. These results describe the observed endpoint and
parser behavior, not a guarantee that every name can be registered.

The normal registered probe was `google.<tld>` where the endpoint returned an
authoritative record. `.zm` used `zicta.zm` because the live `google.zm`
response was an authoritative no-object result. Absence probes used generated,
syntactically valid labels only when the registry returned an exact absence
marker. Captures were reduced to the fields needed by the parser. Contact
values, policy text, and other personal data were removed.

## Safety decisions

Web-only mappings, no-adapter mappings, DNS failures, invalid-query responses,
service outages, and explicit unsupported-TLD notices are not evidence of
registration or availability. The `.video` and `.chat` adapters raise
`Whois::ResponseIsUnavailable` for the observed denial. The `.sm` and `.vu`
adapters do the same for the observed outage and invalid-query responses.
No denial, outage, invalid query, or unknown result is mapped to
`:registered` or `:available`.

The rank sequence in this report is the source sequence from the snapshot:
`.zm`, `.vip`, `.tg`, `.tl`, `.sl`, `.video`, `.sm`, `.home`, `.sb`, `.vu`,
`.jm`, `.fj`, `.chat`, `.je`, `.bs`, `.ls`, `.pr`, `.gm`, `.bj`, `.ht`, `.su`,
`.pg`, `.gp`, `.pn`, `.fun`.
