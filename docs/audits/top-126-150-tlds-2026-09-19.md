# WHOIS parser DNS Magnitude ranks 126-150 audit

Date: 2026-09-19

## Scope and source

This is the next verified range after the Top 100 audit. The ordering is the
ICANN DNS Magnitude snapshot for 2026-09-12, generated 2026-09-18, with the
same delegated, special-use, and undelegated rows retained. The source table
is available at <https://magnitude.research.icann.org/>.

The audit checks current hostname mapping, the actual port-43 response where a
server answered, and the parser result. A denial, refusal, timeout, unsupported
TLD, web-only path, or malformed response is not availability evidence.

## Changes in this range

- Added current-response coverage for `.hn`, `.tn`, `.by`, and `.ve`.
- Added denial and unknown-response guards for `.li`, `.ir`, `.lu`, and `.nu`.
- Added `.host` mapping and an ICANN-compliant parser for its port-43
  availability and registration responses.
- Replaced the stale web-only `.cr` mapping with `whois.nic.cr` and added a
  parser for its current port-43 format.
- The fixtures under
  `spec/fixtures/responses/audit-126-150-2026-09-19/` contain only the
  classification-bearing lines from real responses. Timestamps, contact data,
  and policy text were removed.

Unknown, denial, throttle, timeout, and unsupported responses remain distinct
from `:available` and `:registered`.
