# WHOIS parser audit

Date: 2026-09-19

## Scope

This was a live, point-in-time audit of port-43 WHOIS parsing. We tested one
registered domain and one likely-unregistered domain for each TLD in the union
of the [DNIB Q2 2026](https://www.dnib.com/articles/the-domain-name-industry-brief-q2-2026)
top overall, top ccTLD, and top gTLD lists:

`.com`, `.cn`, `.de`, `.net`, `.org`, `.uk`, `.xyz`, `.ru`, `.top`, `.nl`,
`.br`, `.fr`, `.au`, `.in`, `.eu`, `.info`, `.shop`, `.online`, `.store`,
`.vip`.

A likely-unregistered test input represents an expectation for the test case.
It is not authoritative proof that a domain is available.

## Interpretation

Before the broader update, the existing parser handled six of the 20 TLDs
correctly for both test cases. The expanded pass addressed several current
registry formats and retained explicit unsupported or unknown outcomes where a
reliable port-43 result was not available. Errors, rate-limit responses,
retired WHOIS services, and unsupported formats must not be converted into
positive or negative availability claims.

These results are a point-in-time port-43 parser audit, not an availability
guarantee. WHOIS services and registry formats can change without notice. RDAP
should be preferred where the registry has retired or replaced WHOIS.
