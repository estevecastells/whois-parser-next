# WHOIS parser audit, DNS Magnitude ranks 151-175

Date: 2026-09-19

## Scope and source

This is a point-in-time port-43 WHOIS audit for the entries at daily ranks
151 through 175 in the [ICANN DNS Magnitude snapshot](https://magnitude.research.icann.org/)
for 2026-09-12, generated 2026-09-18. The source rank is retained below,
including special-use and non-delegated strings. These results describe the
observed endpoint and parser behavior, not a guarantee that every name can be
registered.

Registered fixtures use `google.<tld>` where the registry returned a current
record. Absent fixtures use a generated, syntactically valid label where the
registry returned an authoritative absence. Captures were sanitized to remove
contact details and registry disclaimers while retaining the fields needed to
reproduce status, dates, and nameserver parsing.

## Safety decisions

Empty responses, timeouts, connection refusal, web-only mappings, retired
WHOIS notices, and special-use strings remain unknown or unsupported. They are
not converted into `:registered` or `:available` results. Only explicit
registry absence markers are mapped to `:available` in this batch.

The live `.cat`, `.gl`, and `.vg` responses use the CentralNic-style field
layout. `.cat` has a distinct absence phrase, so its parser extends the
CentralNic parser without changing the behavior of existing host mappings.
The `.mk` and `.tz` registered responses contain a domain record but no
`status:` key, so their host parsers derive `:registered` from the absence of
the authoritative `no entries found` marker.
