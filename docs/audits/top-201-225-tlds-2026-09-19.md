## Scope and ordering

This audit continues the Top 100 review using the [ICANN DNS Magnitude
snapshot](https://magnitude.research.icann.org/) for 2026-09-12, generated on
2026-09-18. The ranks below retain the source table's daily-rank positions.
The observation was made against the current port-43 server definitions in
`whois` 6.0.3.

Raw responses were collected on 2026-09-19 where the server was reachable and
then reduced to format-preserving fixtures. Contact, registrar, and other
personal data was removed. The generated absence label was
`codex-20260919.<tld>`.

These are parser and source-support results, not availability guarantees. A
restricted, unavailable, unsupported, refused, ambiguous, or unresolved
outcome remains distinct from an authoritative available or registered result.

## Implementation

The parser additions and fixes are covered by
`spec/whois/parsers/topdomains_201_225_spec.rb` and its isolated fixture tree
under `spec/fixtures/responses/topdomains_201_225/`. The changes deliberately
do not infer registration from a denial, unsupported-TLD response, empty
mapping, or unrecognised status.

The dedicated audit suite passes 21 examples. The focused regression suite,
including the existing `.as`, `.bn`, `.af`, `.gy`, `.mg`, and current parser
fixtures, passes 102 examples with 0 failures. After integration with the
other audit ranges, the full suite passes 6,640 examples with 0 failures.

The audit is point-in-time evidence. Registry formats, access policies, rate
limits, and endpoint availability can change after the observation date.
